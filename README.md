# FIFA-Harmonic-Art-Simulator - PriyanshuK
⚽ World Cup Soccer Harmonograph

An interactive web application that transforms historical soccer match momentum into dynamic 2D geometric art. By mapping minute-by-minute match data (shots, goals, and possession swings) to harmonograph trigonometric curves, each iconic match generates a unique, speed-reactive visual representation of its back-and-forth flow.

🎨 Overview & How It Works

A traditional harmonograph uses pendulums to draw complex geometric figures. In this digital version, the "pendulums" are powered by real-world match momentum:

 Match Data Input: The visualizer reads minute-by-minute timeline data from 5 classic World Cup matches.

 Math Engine: Home and Away momentum values dynamically alter amplitude, frequency ratios, and phase shifts in real time.

 Speed-Reactive Trails: Trajectory lines change color based on the rate of momentum swings—creating vivid rainbow patterns on an HTML5 Canvas as the match unfolds from minute 0' to 90'.

Supported Matches

Users can select and render harmonograph artwork for 5 featured tournament matches:

1 World Cup Final (Spain vs Argentina)

2 3rd Place Play-off (France vs England)

3 Cape Verde vs Argentina

4 England vs Argentina

5 Mexico vs England

🎯 Project Purpose

This project lives at the intersection of data visualization, mathematics, and generative art.

 Mindful Stress Relief: Watching complex harmonograph curves smoothly trace across a dark viewport provides a meditative, satisfying visual experience.

 New Lens for Sports Data: Instead of traditional charts or spreadsheets, match intensity and dramatic late-game comebacks are reinterpreted as aesthetic balance and geometric symmetry.

🔮 Future Roadmap & Physical Concepts

 Expanded Match Database: Incorporate a wider library of historical club and international match datasets, allowing users to upload or select custom match logs.

 Physical Sand Art Harmonograph (Hardware Concept):

 Is a mechanical version possible? Yes! Similar to automated kinetic sand tables (like Sisyphus tables), a physical version can be built using a 2-axis SCARA robot or a polar plotter driven by two stepper motors under a bed of fine sand.

 How it would work: A magnetic ball guided by microcontrollers (Arduino/Raspberry Pi) under the table moves according to the calculated harmonograph coordinates, carving the real-time match trajectory directly into the sand.

 Export & Print Options: Allow users to export high-resolution SVG or PNG artwork generated from their favorite matches to create custom physical prints.
